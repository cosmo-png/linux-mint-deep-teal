# Inspiration notice

Mint Shadow is an independent Linux Mint Cinnamon adaptation inspired by the
settings-panel and quick-control experience in
[DarkShadowShell](https://github.com/shadowww-dev/DarkShadowShell), by
shadowww-dev. DarkShadowShell is licensed under the MIT License.

This repository does not bundle DarkShadowShell's Quickshell source. Its GTK
control center is implemented separately for Cinnamon, which uses a different
desktop stack from the original project's Hyprland and niri targets.
